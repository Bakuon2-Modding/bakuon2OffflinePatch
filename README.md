# 幕オン2 オフライン化パッチ

幕オン2をオフラインでプレイできるようにするパッチです。<br>
サーバーアクセスやニコニコアカウント認証なしでゲームを起動・プレイできます。

---

## 必要環境

- Windows 版の幕末志士の幕末オンライン2 のゲームファイルおよびダウンロードデータ(アセットバンドル)
  - 最新版 (Version 3.2a)
- BepInEx 導入済みの環境

> 本パッチは **Windows 限定**です。Mac・モバイル版には対応していません。

---

## インストール

[こちら](./doc/install_guide.pdf)を参考にしてください

## 主な機能

- **オフライン起動** — サーバー接続なしでゲームが起動・プレイできます
- **ローカルセーブ** — プレイデータはローカルに保存されます（オンラインセーブとは独立）
- **ユーザーコンテンツ** — イラスト・ストーリーの投稿・閲覧がローカルで動作します
- **ステアゲ遺跡・アトラクション・フィールド** — 通常通りプレイできます（ただしオンライン要素は利用不可）
- **ホーム・シティ** — フィールド・NPC(ショップ)が通常通り動作します。

## 使用できない機能
- オンラインマルチプレイ
- 動画再生の絵馬
- 投書箱
- プレゼント抽選

---

## セーブデータについて

オンラインではプレイデータはサーバー上に保存されますが、オフラインモードではローカルに保存されます。<br>
オフライン版では専用の新規セーブデータが作成されます。<br>
オンライン版でのリングやアイテムなどの所持品の引き継ぎはできません。<br>
また、オンラインセーブデータとオフラインセーブデータは互換性がないため、オンライン版のセーブデータにオフライン版のセーブデータを上書きしないでください。
